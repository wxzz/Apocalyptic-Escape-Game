## 一、游戏模式详解
游戏包含**生化生存模式**和**多人死斗模式**两种玩法，规则、目标与特色完全独立。

### 1. 生化模式（僵尸生存）
以波次形式抵御僵尸围攻，坚守存活并清空所有波次敌人即可通关。

- **核心目标**：在僵尸围攻下存活，击杀当前波次全部僵尸，解锁下一波挑战
- **胜利条件**：成功通关全部 10 个波次
- **失败条件**：玩家生命值归零，挑战结束
- **模式特色**
  - 僵尸数量随波次递增，难度逐步提升
  - 第 6 波开始刷新精英僵尸（疾速僵尸、铁壁僵尸、自爆僵尸）
  - 第 10 波刷新终极 Boss 巨型僵尸（基础血量 10000）
  - Boss 存续期间会持续刷新普通僵尸小兵，增加通关难度

### 2. 死斗模式（AI 雇佣兵对战）
清空地图内所有敌方 AI 雇佣兵，获取对局胜利。

- **核心目标**：击杀地图中全部 AI 雇佣兵敌人
- **胜利条件**：成功歼灭全部 12 名敌方 AI
- **失败条件**：玩家生命值归零，对局失败
- **模式特色**
  - 敌方 AI 为自由混战机制，AI 之间会互相攻击、独立作战
  - 每名 AI 随机配备武器（步枪、狙击枪、霰弹枪、手枪）
  - AI 具备智能战术逻辑，可实现走位规避、自主换弹、掩体躲藏等操作

## 二、移动与视角控制
基础移动、视角操控按键，适配全模式通用操作：

| 按键 | 功能说明 |
|------|--------|
| W / A / S / D | 角色前后左右基础移动 |
| 鼠标移动 | 旋转游戏视角、调整瞄准方向 |
| Shift | 奔跑冲刺（移动速度提升，会产生脚步声） |
| 空格键 | 角色跳跃 |
| Ctrl | 下蹲（压低身形隐蔽性提升，小幅降低移动速度） |

## 三、基础战斗操作
全武器通用战斗按键，涵盖射击、瞄准、换弹、武器切换等核心操作：

| 按键 | 功能说明 |
|------|--------|
| 鼠标左键 | 枪械开火 / 近战武器挥刀攻击 |
| 鼠标右键 | 开镜瞄准（仅适配带瞄准镜的武器） |
| R | 手动换弹 |
| 鼠标滚轮 | 顺序循环切换所有携带武器 |
| 鼠标侧键（前进） | 循环切换主武器 |
| 鼠标侧键（后退） | 快速切换副武器 / 近战武器 |

## 四、进阶战术动作
高阶战术按键，适用于对枪、卡点、精准瞄准等实战场景：

| 按键 | 功能说明 |
|------|--------|
| Q | 左向探头（掩体左侧探身瞄准，探头状态无法奔跑） |
| E | 右向探头（掩体右侧探身瞄准，探头状态无法奔跑） |
| 开镜+Shift | 屏息瞄准（消除准星晃动，持续 2 秒，冷却 5 秒） |
| X | 切换射击模式（单发/连发/三连发，仅限适配武器） |
| F | 主瞄/侧瞄模式切换（侧瞄无准星，射击精度小幅提升） |
| Alt | 侧向概略瞄准（枪身侧倾，精度介于腰射和开镜之间） |
| I | 武器检视（查看手中武器细节，检视期间无法射击） |
| Tab | 查看战况面板（存活敌人、击杀数等） |

## 五、武器切换完整逻辑
### 1. 鼠标侧键循环切换顺序
当前主武器 → 手枪（副武器）→ 战术刀（近战）→ 回到主武器

### 2. 数字键快速切换
| 按键 | 切换目标 |
|------|--------|
| 1 | 手枪（副武器） |
| 2 | 当前主武器 |
| 3 | 战术刀（近战） |
| 4 | 投掷物（如有） |

## 七、核心游戏规则
### 通用规则
- 生命值归零即死亡
- 换弹期间：不可射击、不可切换武器、不可冲刺、不可跳跃
- 受击时屏幕边缘闪烁红色，提示伤害来源方向

### 生化模式规则
- 每波僵尸全部击杀后自动进入下一波
- 第 6 波起可能出现精英僵尸（疾速/铁壁/自爆）
- 第 10 波出现 Boss，击杀即可通关

## 八、游玩关键注意事项
- 不同武器影响移动速度：持手枪/刀跑得最快，持狙击枪最慢。
- 侧瞄模式（F）：无准星，适合概略射击，精度介于腰射和开镜之间。
- 开镜时按 Shift 可屏息：减少准星晃动，持续 2 秒，冷却 5 秒。
- 冲刺会发出脚步声：会被 AI 敌人听见并吸引注意。
- 开镜与侧瞄互斥：开镜状态下无法侧瞄，反之亦然。
- 武器检视（I 键）：检视期间不可射击。
- 重型武器（狙击/轻机枪）会降低奔跑移动速度。
